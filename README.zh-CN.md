# Retentide

[English](README.md) | 简体中文

Retentide 是一个面向日常学习的开源背词应用。AI 助教讲解单词、给你出语境练习，FSRS 安排复习，让每个词在你
快要忘的时候回来。名字取自 retention（记忆保持）和 tide（潮汐）：记住的东西会在两次复习之间退潮。

它在浏览器里运行，不需要账号。AI 助教、词典和同步都用你自己的 key。

## 和 AI 助教一起学

接入任意接受浏览器请求的 OpenAI 兼容接口后，AI 助教可以：

- 讲一个词：词根或记忆联想、和形近词与近义词的区别，再给几个新例句；
- 围绕一个词和你对话，对话时它能看到这个词的词条、你的笔记和你答这个词的记录，也可以附上题目截图；
- 用你正在学的词出填空题和同义词选择题（sentence equivalence），风格接近真实考题，并讲解答案；
- 判断你用自己的话写的释义对不对；
- 分析你最近三周的错题，建议接下来练什么。

你的答题记录也可以交给你用的任何 AI：导出成一个 Markdown 文件，或者让 AI 只读查询你的 Supabase 项目
（[配置](docs/supabase.md)）。

## 按计划复习

每天先安排到期的复习，再加固定数量的新词；复习积压时会自动减少新词。每个词什么时候回来由 FSRS-5 决定。

答完不用自己打分。应用根据对错、这一题的用时和你在这类题上的平时速度相比、24 小时内有没有查过这个词来评分，
并在答案页说明依据。可能认识的新词先测再看卡片，生词先看卡片。这些规则是有理由的设计选择，不是已经验证的结论，
细节见 [docs/design.md](docs/design.md)（英文）。

题型会随着掌握程度推进：从识别（英选中、中选英）到英文释义选词、例句填空、选同义词和写释义。形近词和你以前混淆
过的词会被用作干扰项。

## 词表和数据

自带 150 个原创的高阶英语示例词（CC BY 4.0）。你可以导入自己的 CSV 或 JSON 词表，也可以导入题集，格式见
[data/schema.md](data/schema.md)。词库支持搜索、筛选，还有总览视图方便快速扫词。

填入免费申请的 Merriam-Webster key 后可以查释义和读音，只在你主动查词时查询，也不会存进词表（[说明](docs/merriam-webster.md)）。
进度默认保存在浏览器里，连上你自己的 Supabase 项目就能多设备同步。JSON 备份包含当前词表、题集和学习记录；
恢复时还原词表、题集并合并进度。导入的词表和题集不自动云同步，换设备时可以通过备份带过去。界面支持中文和英文。

## 运行

不需要构建。用任意静态服务器打开这个目录：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。部署时把目录放到 GitHub Pages 或任意静态托管即可。在设置里填的 key 只保存在你的
浏览器里。

## 测试

```bash
npm test
```

测试覆盖 FSRS 调度和评分规则、同步合并规则（包括两个标签页同时写入）、词典解析（用手写的测试数据），以及示例词库的
格式。每次推送都会在 CI 上运行。

## 研究问题

应用在每次作答时记录 FSRS 对这一题的事前预测，因此可以在真实使用中检验几个问题。它们是待回答的问题，不是结论：

1. 查词后限制评分，能否减少对“已经记住”的高估（对比下一次无提示复习的预测与实际记住率）？
2. 自动评分能否替代自评而不降低调度质量？学习者自己评的话，有多少次会不一样？（这需要设置自评对照；仅凭日志只能
   衡量现有预测是否校准。）
3. 同一个词，识别题答对能否预示语境题也能答对？

Supabase 结构里的 `retention_v` 是第一个校准视图，回放评估脚本还在计划中。

## 局限

- 不用 Supabase 时，进度保存在浏览器存储里（几 MB），记得不时导出备份。
- AI 服务商需支持 OpenAI 兼容的 Chat Completions、流式回复、JSON 和工具调用，以及浏览器跨域请求（CORS）。
  服务商和模型由你在设置中选择。在浏览器里填的 key，使用同一个浏览器配置的人都能看到。
- FSRS 使用默认参数，暂时没有按个人数据拟合参数。
